Why DualTitle Never Flags Anti-Cheat or Breaks Saves

🛡️

Zero DLL Injection & Zero Hooks

Unlike traditional mod loaders that inject dxgi.dll or dwmapi.dll into the game's binary directory or call OpenProcess, DualTitle renders as an independent Windows DWM topmost desktop window (`WS_EX_NOACTIVATE`).

💾

Automatic Save Backup & Restore

Before applying any audio or subtitle setting, SaveBackupManager snapshots all save files (Saved/SaveGames, PROF_SAVE*, *.sav) into .dualtitle_save_backup/ for 1-click recovery via RestoreSave.exe.

⚡

Universal Multi-Engine Support

Supports Frostbite (.sb / PROF_SAVE_profile), Unreal Engine 4 & 5 (.locres v1–v3, .pak v11, 64-bit Oodle & IoStore .utoc/.ucas), FORGE v27/v50, and .srt/.ass/.json.
